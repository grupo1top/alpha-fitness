# Alpha Fitness — Front-End

Projeto front-end simples para o painel de administração e páginas públicas da academia "Alpha Fitness".

**Descrição:**
- Layouts HTML estáticos com estilos em CSS e interatividade básica em JavaScript.

**Arquivo principal:**
- Página de entrada: [index.html](index.html)

**Outras páginas importantes:**
- [home.html](home.html) — área interna
- [cadastro.html](cadastro.html) — formulário de cadastro
- [lista-alunos.html](lista-alunos.html)
- [lista-funcionarios.html](lista-funcionarios.html)
- [dashboard-financas.html](dashboard-financas.html)
- [folha-pagamento.html](folha-pagamento.html)
- [inventario-patrimonios.html](inventario-patrimonios.html)
- [chamados.html](chamados.html)

**Estrutura de pastas:**
- `css/` — estilos (base, components, global, layout, responsive, style)
- `js/` — scripts (scripts.js)
- `img/` — imagens e logos

**Tecnologias:**
- HTML5, CSS3, JavaScript (vanilla)
